# Política de segurança — projetos-ia

Este repositório contém ferramentas acadêmicas para análise **passiva** e
autorizada de segurança. Não envie segredos, relatórios de clientes, logs privados,
IPs reais, dados pessoais ou exemplos exploráveis em issues públicas.

## Relato responsável de vulnerabilidades

Para suspeitas no próprio código do TramontoSec AI, prepare uma descrição com
versão/commit, comportamento esperado, evidências **sintéticas ou sanitizadas**,
impacto e passos de reprodução não destrutivos. Não publique detalhes de
vulnerabilidades exploráveis, credenciais ou dados de terceiros.

de um canal seguro para divulgação coordenada.

## Escopo e limitações

O software não executa pentest ativo, não altera infraestrutura nem atesta
vulnerabilidades sem revisão humana. A política do produto encontra-se em
[`agents/tramontosec-ai/SECURITY.md`](agents/tramontosec-ai/SECURITY.md).
A presença de um relatório não autoriza avaliação de sistemas externos.
