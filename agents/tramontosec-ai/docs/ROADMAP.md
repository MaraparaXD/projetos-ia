# Roadmap

- **v0.2.1 (recuperada):** núcleo CLI em Python, SQLite com fechamento explícito, testes offline, inspeção Git somente leitura, evidências, importação de metadados de scanners, revisão humana e Ollama local opcional.
- **v0.3 (planejada):** runtime de tarefas, orquestrador e três perfis: Red Team, Static Analysis e Blue Team; políticas verificáveis independentes de LLM; CLI como interface principal.
- **v0.4 (planejada):** dashboard local opcional e protocolos de avaliação de segurança de IA.
- **v1.0 (meta acadêmica):** experimentos comparativos reproduzíveis e documentação metodológica revisada.

**Não foram implementados agentes ofensivos autônomos, scans ativos ou correção automática.**
