# Organização de projetos de IA

Cada projeto em `agents/<nome>/` mantém pacote, testes, exemplos sintéticos,
documentação e dependências independentes. Interfaces web são complementares.
Dados operacionais, modelos, bancos e relatórios ficam fora do Git.
