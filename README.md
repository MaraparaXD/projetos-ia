# Projetos IA

Monorepositório de projetos, ferramentas e agentes de Inteligência Artificial.

Cada agente terá sua pasta em `agents/`, com código, testes, documentação e dependências próprias.

## Agentes

- **TramontoSec AI** (em recuperação): auditoria de segurança com núcleo Python, seguindo o Tramonto; evolução planejada para perfis Red Team, análise estática e Blue Team.

## Organização planejada

```text
projetos-ia/
├── agents/
│   ├── tramontosec-ai/
│   └── outros-agentes-no-futuro/
├── docs/
├── .gitignore
└── README.md
```

**Privacidade:** não publicar código proprietário, evidências de auditoria, dados de clientes, logs, senhas ou chaves. O repositório é público.

Código de cada agente deve ser testado, documentado e desenvolvido de forma independente.
